# Smart Contracts Addresses

PrimeFi v2 is deployed on three EVM chains, each with its own set of contracts. Pick the chain you want to inspect:

* [Base Network Deployment Addresses](base-network-deployment-addresses.md) — chain id `8453`
* [HyperEVM Deployment Addresses](hyperevm-deployment-addresses.md) — chain id `999`
* [XDC Network Deployment Addresses](xdc-network-deployment-addresses.md) — chain id `50`

The app's **v3** selector includes PrimeFi-operated XRP testnets and the separate **Fathom Lending** market on XDC. This address section lists Fathom's XDC deployment for convenience; PrimeFi does not operate those contracts:

* [Fathom v3 (XDC) Deployment Addresses](fathom-xdc-deployment-addresses.md) — chain id `50`, operator: Fathom Protocol
* See also: [Fathom v3 (XDC) overview](../fathom-v3/README.md)

{% hint style="warning" %}
PrimeFi v2 and Fathom v3 both operate on XDC chain ID `50`, but they use different contracts and operators. Confirm the selected app market and compare addresses with the appropriate page before signing.
{% endhint %}
