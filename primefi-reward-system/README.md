# PrimeFi Reward System

PrimeFi's reward system combines standard lending-protocol incentives with conditional programs for qualifying pLP and PRFI NFT participants. Eligibility, rates, and distributions depend on live market activity, current contract configuration, program terms, exclusions, and available funding. Nothing in this section promises a guaranteed payout, APR, or yield.

## PRFI NFT Rewards and planned revenue sharing

The live PRFI NFT staking flow lets users deposit PRFI into PRFI NFTs and participate in configured staking rewards. This is separate from the planned use of NFTs as collateral in PrimeFi lending markets; NFT-as-lending-collateral is not part of the live PRFI NFT staking flow.

A separate revenue-share concept has been described as allocating 40% of PrimeFi lending-and-borrowing protocol profits to qualifying PRFI NFT participants. That component is **planned, not currently documented as an active on-chain distribution**. It does not create a current entitlement or guaranteed yield. Activation requires a public definition of profits, exclusions, eligibility, distribution contracts, and verifiable on-chain configuration.
