# Flik into pLP

When we use the **“Flik rewards into pLP”** feature (that is, the rewards accumulated on the network or networks where we currently have an active pLP position), those rewards are automatically converted into a **new locked pLP position**.



{% hint style="warning" %}
It’s important to keep in mind that, just like reward claims can only be made on **Base Network**, this feature works the same way. That means the new position will also be created **on Base Network**.
{% endhint %}
