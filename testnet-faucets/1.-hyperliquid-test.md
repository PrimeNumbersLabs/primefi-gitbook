# 1.-Flare Coston2

To test the [Flare Coston2 XRP market](../xrp-testnet-markets/flare-coston2.md) you need **C2FLR** for gas first, then the mintable reserve tokens.

### Step 1 — Get C2FLR (gas)

Claim test C2FLR from the official Coston2 faucet. Paste your wallet address and claim.

{% hint style="success" %}
You only need a small amount of C2FLR — it just pays transaction fees.
{% endhint %}

{% embed url="https://faucet.flare.network/coston2" %}
Coston2 Gas Faucet
{% endembed %}

### Step 2 — Mint test reserves

In the PrimeFi app, switch to **v3 → Flare Coston2**, connect your wallet, and click **Get test tokens** above the markets table. You can mint any single token or **Mint all** at once:

| Token | Amount per mint |
| ----- | --------------- |
| FXRP | 100,000 |
| RLUSD | 100,000 |
| stXRP | 100,000 |
| USDT0 | 100,000 |
| WBTC | 10 |
| FBTC | 10 |
| WETH | 100 |

{% hint style="info" %}
These are mintable test mocks — minting is unrestricted, so you can top up any time. On mainnet, FXRP is minted from real XRP via Flare [FAssets](https://dev.flare.network/fassets/overview) instead.
{% endhint %}

Once funded, head to the dashboard and start supplying/borrowing.
